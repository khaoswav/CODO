# CODO

**Think. Code. Create.**

CODO is a native macOS development command center for building and managing software projects.

## Product direction

- Native SwiftUI for macOS
- Dark workspace with violet accent
- Project-centric navigation and task workspace
- Local-first project management
- Extensible integrations for Xcode, Unity, Git, GitHub, and Goose

## Development status

Initial repository bootstrap. The first milestone establishes the macOS app shell, design tokens, dashboard, and workspace navigation.

## Requirements

- macOS 14+
- Xcode 16+
- Swift 5.10+

## Build

Open `CODO.xcodeproj` in Xcode and run the `CODO` scheme.
